Aegis Sovereign Vault (v2.0)
نظام تشفير سيادي عالي الأمان مصمم بلغة Rust، يركز على حماية البيانات الحساسة وتأمين الذاكرة من الهجمات.
🛡️ المميزات التقنية (Technical Features)
تشفير متدفق (Streaming Encryption): يعتمد على AES-256-GCM لتشفير الملفات الكبيرة دون استهلاك ذاكرة الرام.
اشتقاق مفاتيح متطور (Key Derivation): يستخدم Argon2id (بمعايير OWASP 2023) لضمان أقصى حماية ضد هجمات القوة الغاشمة.
أمان الذاكرة (Secure Memory): يتم مسح بيانات كلمة المرور والمفاتيح من الذاكرة فور الانتهاء منها باستخدام zeroize.
الإتلاف الآمن (Secure Shredding): يقوم بإعادة الكتابة فوق الملفات الأصلية ثلاث مرات قبل حذفها لمنع استعادتها.
واجهة تفاعلية (GUI): واجهة رسومية بسيطة مبنية باستخدام iced مع دعم التحديث المباشر لشريط التقدم.
⚙️ المتطلبات (Requirements)
هذا المشروع يتطلب تثبيت Rust و Cargo على جهازك للقيام بعملية البناء (Compilation).
🚀 كيف تشغل المشروع؟
قم بنسخ المستودع: git clone [رابط-المستودع]
ادخل للمجلد: cd the-fulcrum
قم ببناء المشروع: cargo build --release
شغل التطبيق: ./target/release/aegis-vault
