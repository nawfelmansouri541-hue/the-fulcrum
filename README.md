# The Fulcrum - Aegis Sovereign Vault
نظام تشفير سيادي معزول يعتمد على بروتوكول Aegis لحماية البيانات.

## المميزات:
- تشفير AES-256-GCM عالي الأمان.
- اشتقاق مفاتيح آمن باستخدام PBKDF2.
- معالجة بيانات غير متزامنة (Async Streaming).

## كيفية التشغيل:
1. تأكد من تثبيت Rust على نظامك.
2. استخدم `cargo run` لتشغيل النواة.
